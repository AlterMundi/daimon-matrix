## Authority and protocol findings

- The original “through Tribe direct audiences” wording contradicted the
  DM-050–DM-054 replacement architecture. The final wire is independently
  implemented in `daimon-matrix`; Tribe carries no Matrix peer traffic.
- Every encrypted envelope binds the exact being/manifest, active sender body,
  embodiment, incarnation, credential, principal and signing key, plus the
  exact active recipient credential/encryption key, issue/expiry, content type,
  correlation and reply parent.
- Signature verification precedes private-key unwrap. Canonical/duplicate/open
  JSON, profile, authority, recipient, origin, revocation, expiry, content type
  and size substitutions fail under one stable external rejection.
- Transport dispatch is closed to existing DM-054 scope and DM-023 sync
  handlers. Pull remains import-not-adoption and three one-event pages retain
  the actual remote origin.

## Crash, custody and carrier findings resolved

- Initial runtime custody attempted to reuse the password callback on every
  peer operation. Real daemon descriptors are one-shot. Bundle loading now
  opens the authenticated rollback-bound keystore once, validates the exact
  public/private key bindings and retains only the required purpose-bound
  seeds. A strict one-shot test executes real post-load crypto.
- Initial HTTP concurrency was bounded only after a handler thread existed.
  The server now rejects excess accepted connections before thread allocation,
  applies finite socket reads, exact media type/content length, banner-free
  empty errors and closed response validation. HTTP 503 and connection loss are
  explicitly ambiguous and retry the frozen request.
- Inbound leases initially allowed an expired claimant to finish if no
  successor had arrived. Finish now requires the exact still-live claim;
  takeover rejects stale completion. Real concurrent duplicate, takeover,
  conflict and corrupted response digest cases are covered.
- Sender outbox and receiver exchange stores validate byte hashes on every
  replay and map SQLite corruption to the stable fail-closed protocol error.
  Reconstructed outbox and dispatcher instances return the same frozen request
  and committed response after simulated restart/response loss.
- Package allowlists and reproducible-build inputs initially omitted the new
  module. Both sdist and wheel now contain exactly `peer_transport.py`, and CI
  runs its source and installed-wheel tests.
- Adding a module legitimately changed Hermes' content-addressed Matrix package
  evidence. The audited DM-041 generator refreshed only its provenance/index/
  valid receipts, and regeneration is byte-identical.
