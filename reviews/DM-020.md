## Build and artifact contract

- Python 3.11 through 3.14 are explicit public CI targets; package metadata
  requires Python 3.11 or newer.
- Hatchling 1.31.0 is the exactly pinned PEP 517 backend and `build` 1.5.0 is
  the exactly pinned frontend. `SOURCE_DATE_EPOCH=946684800` fixes archive
  timestamps above the ZIP timestamp floor.
- Two separate temporary source roots and two separate isolated backend
  environments must produce byte-identical sdists and wheels.
- The sdist and wheel have closed allowlists. Metadata, empty
  `Requires-Dist`, pure-Python wheel tag, source bytes, timestamps, paths,
  permissions, link types, and every wheel `RECORD` hash and size are checked
  without extracting either archive.
- A `MANIFEST.in` is deliberately unnecessary: Hatchling's target selection
  is closed in `pyproject.toml`, and the independently tested artifact
  allowlists are the acceptance boundary.
- The secret scanner rejects private-key signatures, common credential
  signatures, SQLite/WAL state, caches, generated metadata, private filenames,
  message/state/runtime directories, experimental modules, unsafe paths,
  symlinks, special members, and oversized inputs.

## Adversarial findings resolved

- Archive paths are treated as POSIX paths and reject absolute, backslash,
  empty, dot, and parent segments before any content is read.
- Tar links/special members and ZIP symlinks/special members fail closed; ZIP
  producers that carry permission bits without file-type bits remain valid.
- Secret signatures in the scanner implementation are assembled from public
  fragments so scanning the scanner itself does not require an exclusion.
- Rejected fixtures assemble dummy credential, private-key, and SQLite
  signatures at test time, preventing both fixture false positives and a
  weakened production detector.
- Artifact inspection requires the exact normalized root and filenames,
  preventing a valid payload from hiding beside an unexpected file.
- The wheel installation check uses `--no-deps` in a new environment and
  verifies both the public version and absence of runtime requirements.
